# Objective-specific structural evidence

The compact files here support the claims that:

1. the Sinusoidal task-loss frontier is not an artefact of retaining only the
   loss-selected restart;
2. direct-displacement optimisation can attain a larger global displacement
   while preserving much higher accuracy than task-loss optimisation at the
   same checkpoint and native budget; and
3. the two objectives allocate displacement differently across layers.

The full raw all-restart and direct-displacement archives, including saved
perturbation tensors, are packaged separately as the GitHub Release asset
`PE_ROBUSTNESS_OBJECTIVE_AUDITS_RAW_v1.0.0.zip`.
