# Pre-submission checklist

The repository package is internally verifiable offline. The following external item cannot be established by the offline release verifier and must be checked immediately before manuscript submission:

- [ ] Confirm that `https://github.com/djokobandjur/vit-pe-decoupling` is publicly accessible from a logged-out/incognito browser and that the tagged release corresponds to this package.

This item is intentionally not represented as an automated PASS gate because repository visibility is an external hosting state rather than a property of the archived bytes.
