# Historical cross-hardware evidence

`POINT_3_5_AUDIT_REPORT_CANONICAL_v10.md` is the retained historical audit
summary that reports the seed-42 H200 recheck against earlier RTX Blackwell
Server Edition values. It records maximum absolute differences of `0.000491`
in normalized accuracy and `2.55718e-05` in achieved rho.

`D033A_PROVENANCE_REPORT.json` records the canonical ViT-B and ViT-S engine
hashes, split hashes, and numerical provenance available for the later audit.
Its historical-reconciliation status is retained verbatim.

The earlier raw Blackwell log and a row-level paired hardware-comparison file
are not redistributed. Therefore the manuscript describes the numerical
agreement as an **audit-recorded cross-hardware check**, not as a publicly
rerunnable paired hardware experiment. Only the homogeneous H200 values enter
the final six-seed grid.
